### Frame 流与多帧交换语义（阶段 5 当时实现）

```text
Camera2.capture
  -> Camera2FrameScheduler.frames(): Flow<Frame>
  -> MahjongSceneProvider.start().collect
  -> MahjongCloudService.submitImage
  -> POST /api/v1/mahjong/sessions/{session_id}/analyses
  -> SceneResult
  -> SdkEvent.ResultReceived
  -> MainActivity 当前结果区域
```

- Flow 使用顺序 `emit`：当前 Frame 完成读取、上传、映射和临时文件删除后才等待下一采集周期，不会并发提交多帧。
- 一次场景只创建一个云端 session；停止、后台、取消或错误时调用 `/end` 并释放 Camera2。
- `ConnectionConfig.serverUrl` 映射到 `MahjongSceneConfig.serverBaseUrl`，FPS 映射为采集间隔；API Key 不写入场景普通配置。
- 上述链路是阶段 5 的历史实现；阶段 9 已改为 `DefaultSessionManager -> MahjongSession.processFrame()`，当前结构以阶段 9 为准。

### API Key 配置

- `local-token` 是本地开发服务与客户端约定的访问凭据，不是麻将 session ID。
- `server/run_local.py` 默认设置 `CLOUD_API_KEY=local-token`；客户端通过 `X-API-Key` 请求头发送。
- 云端可使用 `-PCLOUD_API_KEY=<云端实际值>` 覆盖；`/health/ready` 不校验该凭据，创建 session、上传分析和结束 session 都会校验。
